# KOOWEXA — aplicación estática

Módulos: KW (configurador y factura proforma PDF), KX (conversor con tasa manual), AC (progreso local) y PX (promoción del ecosistema).

## Despliegue
Publica la raíz como sitio estático. No requiere PHP, Python ni base de datos.

## Google Search Console
Se conserva google90ee1fce91836ef4.html. No cambies su contenido. Confirma que robots.txt y sitemap.xml apunten al dominio definitivo antes del lanzamiento.

## Límites
La factura es proforma y se genera en el navegador. Las tasas son manuales. Los textos legales deben revisarse para reflejar los datos reales de la plataforma.

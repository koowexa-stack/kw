# KOOWEXA

Reconstrucción estática del ecosistema KOOWEXA (KW, KX, AC y PX).

La versión de despliegue se organiza en HTML, CSS y JavaScript nativo; no requiere PHP ni Python en producción. La configuración de dominio y la verificación de Google Search Console deben conservarse al publicar.

> La implementación completa se está preparando en una rama dedicada para revisión antes de integrarse en `main`.
